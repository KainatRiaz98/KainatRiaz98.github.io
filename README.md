# kainatriaz98.github.io

Personal CV site for Kainat Riaz, published at <https://kainatriaz98.github.io>.

- `index.html` — the CV page (self-contained; fonts from Google Fonts, no build step)
- `kainat_riaz_cv.pdf` — the same CV as a PDF, linked from the page
- `.nojekyll` — serve files verbatim, skip Jekyll processing

To update: edit `index.html`, commit, push. GitHub Pages rebuilds in under a minute.
